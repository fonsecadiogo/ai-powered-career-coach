# Team Project and Contributions

## Project context

AI-Powered Career Coach (Atena) was developed collaboratively as an Ironhack
AI Engineering bootcamp project. The repository represents the team's shared
delivery and should not be presented as the work of one person alone.

The application combines a React/Vite frontend with a FastAPI/Python backend
and currently includes mock interviews, CV review, Himalayas job discovery, and
job-fit analysis.

## Portfolio attribution

When presenting this repository, contributors should distinguish between:

- the functionality delivered collaboratively for the bootcamp;
- individual contributions made by each team member;
- later personal experiments or extensions built outside the shared delivery.

Caio's personal career-intelligence work may be developed in a separate
repository derived from this foundation. That repository should preserve the
original project's attribution and clearly identify which changes were made
after the bootcamp delivery.

## Contribution expectations

- Keep secrets, personal CVs, identity documents, and private application data
  out of the repository.
- Add tests for behavior changes and update the README when public interfaces
  change.
- Preserve the existing contributor history when adapting the project.
- Discuss substantial architectural changes with the team before merging.
